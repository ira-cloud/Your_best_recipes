# Передача контекста (для новой сессии Claude)

Прочитай `README.md` и `CLAUDE.md` в этой папке, потом этот файл.

## Задача
Инструмент автомонтажа Reels для блога «Твоя нутрипродвинутая подруга» (питание женщин по состоянию тела, автор не врач).
Дубли с суфлёра по 1–2 фразы → склейка, вырезка пауз, субтитры, вставки в стиле бренда → ручные правки → экспорт.

## Этапы
1. **Тест на одном ролике (текущий).**
   - Склейка; вырезать паузы > 0,4 с и оговорки; список вырезанного с таймкодами (`output/cuts.md`).
   - Субтитры Whisper (русский): 2–4 слова на экран; ключевое слово #C96F4A, остальное #F5EFE6 с мягкой тенью или плашкой #2B2B2B; безопасная зона (≈35–68 % высоты, отступ справа ~150 px); Montserrat ExtraBold; проверить медицинские термины.
   - Звук: highpass + лёгкий шумодав + loudnorm −14 LUFS + лимитер.
   - Последний кадр ~2 с: мелко «Образовательный контент, не заменяет консультацию врача».
   - Экспорт: MP4 1080×1920, H.264, 30 fps, AAC + .srt + `output/edit.json` (куски и субтитры для правок).
   - Дальше правки текстом: «субтитр на 0:12 исправь», «верни кусок 0:20–0:23».
2. **Шаблоны бренда (Remotion):** 3 стиля субтитров, вставка «цифра с источником», бейдж «Серия N/7», финальный кадр с CTA.
   Палитра: молочный #F5EFE6, шалфей #5E7A66, терракота #C96F4A, графит #2B2B2B.
3. **Редактор:** визуальная правка субтитров, границ кусков, вставок, музыки, обложки (Remotion Studio), экспорт одной командой.
