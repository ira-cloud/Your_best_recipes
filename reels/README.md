# Reels-автомонтаж — «Твоя нутрипродвинутая подруга»

- `input/` — сырые дубли с суфлёра (исходники, только чтение) + `script.txt` — текст суфлёра, если есть.
- `output/` — всё, что делает инструмент: черновик `*.mp4`, `*.srt`, список вырезанного `cuts.md`, проект правок `edit.json`.
- `templates/` — шаблоны бренда (этап 2, Remotion): стили субтитров, вставки, бейдж «Серия N/7», финальный кадр.
- `tools/` — скрипты монтажа (появятся на этапе 1).
- Палитра: молочный #F5EFE6, шалфей #5E7A66, терракота #C96F4A, графит #2B2B2B. Шрифт: Montserrat ExtraBold.
- Правила работы с папкой — в `CLAUDE.md`.
