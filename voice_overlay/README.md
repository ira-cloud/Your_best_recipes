# Голос → текст поверх всех окон

Маленькое окно, которое всегда остаётся сверху. Вы работаете в любом приложении,
нажимаете **Ctrl+Alt+Пробел**, говорите, снова нажимаете **Ctrl+Alt+Пробел**,
и текст появляется в окне. Если включено, он сразу вставляется туда, где стоит курсор.

## Установка (Windows / macOS / Linux)

1. Установите Python 3.10+ (на Windows отметьте «Add Python to PATH»).
2. В папке с программой выполните:
   ```
   pip install -r requirements.txt
   python voice_overlay.py
   ```
   При первом запуске скачается модель распознавания (~500 МБ для `small`).
   Дальше всё работает без интернета.

## Настройки (в начале `voice_overlay.py`)
- `MODEL_SIZE`: `base` быстрее, `medium` или `large-v3` точнее.
- `LANGUAGE`: `"ru"`, или `None` для автоопределения языка.
- `HOTKEY`: сочетание клавиш.

## macOS
Дайте терминалу (или Python) доступ в «Настройки → Конфиденциальность»:
**Микрофон**, **Универсальный доступ** и **Мониторинг ввода**. Без этого не будут
работать горячая клавиша и автовставка.
